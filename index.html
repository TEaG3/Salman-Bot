⚙️ محركات الذكاء الاصطناعي المجانية

اربط سلمان بأي محرك سحابي مجاني عالمي. الافتراضي يعمل فوراً بدون مفتاح، والمفاتيح تُخزَّن في متصفحك فقط.

🔑 روابط المفاتيح المجانية:
• Gemini: aistudio.google.com/apikey
• Groq: console.groq.com/keys
• OpenRouter: openrouter.ai/keys
• Mistral: console.mistral.ai/api-keys
• Cohere: dashboard.cohere.com/api-keys
• GitHub Models: GitHub Tokens

☁️ سحابة GitHub — مزامنة ونشر مجاني

استخدم مستودعك كقاعدة بيانات سحابية مجانية لمزامنة محادثاتك وتقاريرك بين جميع أجهزتك، وانشر الموقع مجاناً على GitHub Pages.

🚀 النشر المجاني على GitHub Pages

  1. اضغط «تحميل index.html للنشر» أعلاه.
  2. في مستودعك: Add file → Upload files وارفع الملف.
  3. اذهب إلى Settings → Pages واختر main / (root) ثم Save.
  4. موقعك: https://teag3.github.io/Salman-Bot/
