# Salman Bot

واجهة مساعد ذكي عربية مع محادثة وأدوات للصور والفيديو والتقارير والعروض.

## النسخة الجديدة — Ruby API + ChatGPT-style UI

المشروع مقسوم إلى جزأين مستقلين:

- **الواجهة الثابتة:** HTML/CSS/JavaScript وتستمر على GitHub Pages.
- **الخادم:** Ruby on Rails 8 API في المستودع نفسه، لكنه يُنشر كخدمة ويب مستقلة.

GitHub Pages لا يشغّل Ruby؛ لذلك لا بد من نشر مجلد المشروع كخدمة Ruby مستقلة (Render أو Fly.io أو VPS) ثم إدخال رابطها من زر **اتصال خادم Ruby** في الواجهة.

راجع [README-RUBY.md](README-RUBY.md) لإعداد Ruby محلياً والنشر وإعداد PostgreSQL وCORS.

## الحالة الحالية

- تمت إضافة أساس Rails API ونقطة فحص صحة الخدمة `/api/v1/health`.
- أضيف شريط جانبي للتنقل وواجهة أقرب إلى ChatGPT.
- أضيف إعداد لحفظ عنوان خادم Ruby وفحص اتصاله.
- محركات الذكاء الاصطناعي الحالية بقيت كما هي؛ لم يتم تحويل مفاتيحها إلى الخادم بعد.
- لا تُحفظ المحادثات على الخادم في هذه المرحلة.

لا تضع مفاتيح API أو GitHub Tokens داخل ملفات المستودع.
