# Salman Bot

واجهة مساعد ذكي عربية مع أدوات الصور والفيديو، ومنشئ أتمتة بمساعدة الذكاء الاصطناعي.

## البنية
- واجهة ثابتة HTML/CSS/JavaScript على GitHub Pages.
- خادم API مستقل بـ Ruby on Rails 8.
- PostgreSQL لتخزين الأتمتات ونتائج تشغيلها.
- محركات الموقع السابقة محفوظة؛ صفحة `automations.html` تضيف مساحة عمل جديدة ولا تستبدل الاستوديوهات الحالية.

## منشئ الأتمتة
افتح [automations.html](./automations.html) من الموقع. اكتب وصف الأتمتة بالعربية، اطلب من Salman-Bot إنشاء مسودة، راجع الخطوات، ثم احفظها أو شغّلها. يدعم الإصدار الأول خطوات آمنة: تسجيل رسالة، تعيين متغير، وفحص شرط. لا يشغّل كوداً عشوائياً أو أوامر نظام أو روابط غير موثوقة.

## إعداد الخادم
راجع [README-RUBY.md](README-RUBY.md) و[README-AUTOMATIONS.md](README-AUTOMATIONS.md).

المتغيرات المطلوبة على الخادم:
- `DATABASE_URL`
- `FRONTEND_ORIGIN=https://teag3.github.io`
- `SALMAN_API_TOKEN` رمز طويل وعشوائي لحماية API
- `OPENAI_API_KEY` لتفعيل إنشاء مخططات الأتمتة بالذكاء الاصطناعي
- `OPENAI_MODEL` اختياري

لا تضع المفاتيح في GitHub أو JavaScript. رمز الواجهة يُحفظ في sessionStorage للجلسة الحالية فقط. قبل إطلاق الخدمة لعدة مستخدمين، يجب إضافة تسجيل دخول وصلاحيات منفصلة لكل مستخدم.

## الجدولة
الأتمتات المجدولة في هذه النسخة تعمل مرة واحدة. يلزم إعداد cron موثوق على الخادم لتشغيل `bundle exec rake automations:run_due` دورياً. بعد نجاح المهمة تُوقَف تلقائياً.

## النشر والحالة
GitHub Pages لا يشغّل Ruby. انشر Rails كخدمة HTTPS منفصلة، شغّل `bundle exec rails db:migrate`، ثم أدخل رابط الخادم ورمز الوصول في صفحة منشئ الأتمتة. لا يعني وجود الكود في المستودع أن خادم API قد نُشر أو أن مفتاح الذكاء الاصطناعي قد أُعد.
